# Caselaw Query Regeneration Workflow

## Initial Inputs

The original dataset can be found in `https://github.com/harsha-simhadri/big-ann-benchmarks/blob/main/dataset_preparation/caselaw_dataset.md`.
The single-vector datasets can be generated by `multi_vector_utils.py1 which also provided by big-ann-benchmarks.
Assume the workflow starts with the following files.

### Baseset

```text
caselaw_base_single_vector_embeddings.bin
caselaw_base_single_vector_metadata.jsonl
```

### Queryset

```text
caselaw_query_single_vector_embeddings.bin
caselaw_query_single_vector_filters.jsonl
```

### Groundtruth

```text
caselaw_singlevec_gt.bin
```

## Step 1: Filter Queries by GT Count

Use `regenerate_query.py`.

This step keeps only queries whose filtered groundtruth count is greater than N (N = 100 by default).

```bash
python3 regenerate_query.py \
  --query-bin /path/to/caselaw_query_single_vector_embeddings.bin \
  --query-dtype float32 \
  --query-filters /path/to/caselaw_query_single_vector_filters.jsonl \
  --gt-bin /path/to/caselaw_singlevec_gt.bin \
  --min-gt 100 \
  --out-query-bin /path/to/caselaw_query_single_vector_embeddings_100.bin \
  --out-query-filters /path/to/caselaw_query_single_vector_filters_100.jsonl \
  --out-gt-bin /path/to/caselaw_singlevec_gt_filtered_100.bin
```

Outputs:

```text
caselaw_query_single_vector_embeddings_100.bin
caselaw_query_single_vector_filters_100.jsonl
caselaw_singlevec_gt_filtered_100.bin
```

Keep the default behavior. `regenerate_query.py` will remap `query_id` in the output JSONL to `0..N-1`.

## Step 2: Compute Selectivity Summary

Use `check_selectivity.ipynb`.

Set the notebook paths to:

```python
query_path = Path("/path/to/caselaw_query_single_vector_filters_100.jsonl")
base_path = Path("/path/to/caselaw_base_single_vector_metadata.jsonl")
```

Run all cells.

The notebook will produce:

```text
query_selectivity_summary.csv
```

Expected CSV format:

```csv
query_id,hit_count,total_base,selectivity
0,438792,7414023,0.05918406241793423
1,6529,7414023,0.0008806285062779006
```

## Step 3: Split by Selectivity Bucket

Use `regenerate_query_by_selectivity.py`.

Example for bucket `[0.005, 0.01]`:

```bash
python3 regenerate_query_by_selectivity.py \
  --query-bin /path/to/caselaw_query_single_vector_embeddings_100.bin \
  --query-dtype float32 \
  --query-filters /path/to/caselaw_query_single_vector_filters_100.jsonl \
  --gt-bin /path/to/caselaw_singlevec_gt_filtered_100.bin \
  --summary-csv /path/to/query_selectivity_summary.csv \
  --min-selectivity 0.005 \
  --max-selectivity 0.01 \
  --num-queries 10000 \
  --out-query-bin /path/to/caselaw_query_single_vector_embeddings_100_sel_0.005_0.01.bin \
  --out-query-filters /path/to/caselaw_query_single_vector_filters_100_sel_0.005_0.01.jsonl \
  --out-gt-bin /path/to/caselaw_singlevec_gt_filtered_100_sel_0.005_0.01.bin
```

Repeat for other buckets, for example:

```text
0.005 - 0.01
0.01  - 0.1
0.1   - 0.5
```

## Full Workflow

```text

        |

        |

        |

```
